# skill-viewer · 轻量 Skill 全览

> 把 skills CLI 装出的几十个技能整理成"**仓库 → 子技能**"的本地知识库:可搜索、可归类、左英右中逐段对照阅读。只读，不安装、不卸载。

## 项目背景

[vercel-labs/skills](https://github.com/vercel-labs/skills) 等 CLI 会把一个仓库的几十个子技能平铺装进本地目录，还会被 `.agents` / `.zcode` / `.claude` 多个工具根共享。时间一长:

- 技能文件夹混在一起，**哪个属于哪个仓库不可见**；
- SKILL.md 几乎全是英文，阅读吃力；
- 同一技能在多个工具根出现，像装了好几份。

skill-viewer 一次扫描，把这些问题全部理清。

## 他有什么用

- 想知道**某个技能来自哪个仓库**——精确读安装清单，不是猜；
- 想**对照中文**读英文技能文档；
- 想看清**哪些工具根目录在生效**、哪些是拷贝、哪些分岔了；
- 想**手动归类**技能，或确认自动推断的结果。

## 核心卖点

- **lock 归属引擎**:优先读 skills CLI 安装清单 `.skill-lock.json`，瀑布式补充 `.git` 远端、frontmatter 来源(标注"创作上游")与 LLM 推断(标注"待确认")；手动归组永远最高优先级。
- **块级中英对照**:左原文右译文逐段对齐；代码块、命令、URL、路径、环境变量先摘出、译后回填，绝不被改写；中文原文单栏直出。
- **多根去重**:junction/symlink 按真实路径合并；内容一致的拷贝合并计数；同名分岔展示为多个版本。
- **积分友好**:打开哪篇才翻译哪篇；内容未变永不重复调用；并发只翻一份；自动分块与节流。
- **双形态**:网页版(Node ≥ 20)与桌面版(免 Node、托盘常驻)共享同一界面与数据。

## 快速开始

### 网页版

前置:[Node.js](https://nodejs.org/) ≥ 20(零 npm 依赖，无需 `npm install`，可用 `node -v` 检查)。

```bash
node server.js
# 打开 http://127.0.0.1:4763
```

### 桌面版(Windows)

运行 `desktop/target/release/skill-viewer-desktop.exe`(单文件，免安装)，或用安装包 `desktop/target/release/bundle/nsis/skill-viewer_0.1.0_x64-setup.exe`。默认托盘常驻:点关闭最小化到托盘，托盘右键退出；开机自启与"关闭即退出"在设置页开启。

### 配置翻译与 LLM

右上角 **⚙ 设置**:

- **翻译服务**:使用UApiPro云翻译服务。粘贴 API key → 「测试连通(免费)」→ 保存，即可开启中英对照；
- **LLM 服务**:选预设(DeepSeek / 智谱 GLM / 自定义 OpenAI 兼容)→ 填 key → 「测试连通」→ 保存，可生成中文概述与归属推断。

不配置 LLM 也能正常使用:概述降级为原文描述，其余功能不受影响。翻译走 uapis.cn AI 翻译接口(4 积分/次)，首次使用会弹出隐私确认。

### 常用参数

```bash
node server.js --port 4763 --host 127.0.0.1 --config config.json --no-scan
```

## 安全与隐私

**API key(机密)**

- 只在设置页录入，经 **OS 凭据库(Windows DPAPI)+ AES-256-GCM** 加密后落盘，任何文件中都没有明文；
- 永不以明文回传浏览器:界面和所有接口只显示 `前3***后4` 掩码；
- 凭据文件复制到其他机器或用户后无法解密；可随时在设置页「清除已存」。

**本地 API**

- 服务只监听 `127.0.0.1`，外部机器无法访问；
- 所有状态变更请求(POST)强制**同源校验**:伪造 Host/Origin 的跨站写入与 DNS rebinding 一律拒绝(403)，浏览器里的其他网页改不了你的配置；
- 任何接口的响应都不含完整 key；缓存、索引、状态文件中同样没有明文。

**文档内容**

- 翻译与 LLM 概述会把**所浏览文档的原文**发送到对应外部服务——翻译前必须明确同意，未同意只展示原文；
- 代码块、命令、路径、环境变量先摘出再翻译，不经翻译服务改写；
- 扫描、归属、搜索全部在本地完成；不配置 LLM 时除翻译外无任何外发。

## 配置(可选)

`config.json` 全部字段有默认值，`~` 会展开为用户目录，复制 `config.example.json` 为 `config.json` 即生效:

| 字段 | 说明 |
| --- | --- |
| `roots` | 技能根目录列表，按真实路径去重扫描 |
| `lockFiles` | 安装清单文件列表 |
| `dataDir` | 缓存目录(索引/概述/译文/手动归组) |
| `providers.translate` | 翻译服务端点与参数(密钥不在此，走加密存储) |
