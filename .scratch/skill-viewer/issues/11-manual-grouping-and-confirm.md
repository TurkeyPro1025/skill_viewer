# 11: 手动归组与推断确认（overrides）

**What to build:** UI 支持多选技能手动归入某仓库或移入"未知来源"、一键确认 LLM 推断的归属结果；归组写入 overrides 数据文件，优先级高于一切自动归属；重新分析（含手动更新）时手动结果永不丢失。

**Blocked by:** 04（归属补充链与未知来源分组）、10（LLM provider 与归属推断——确认推断需要推断先存在）

**Status:** ready-for-agent

- [ ] 多选技能可归入任意仓库组或移出分组
- [ ] 推断结果可一键确认，确认后不再显示"推断"标记
- [ ] overrides 优先级最高：自动分析结果变化不覆盖手动归组
- [ ] 重分析/手动更新后手动归组仍然保留（fixture 断言）
