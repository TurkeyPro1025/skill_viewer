没有匹配的技能

翻译前请确认

开启中英对照阅读需要把文档原文内容发送到外部翻译服务（uapis.cn AI 翻译接口）。

  • 上传内容仅限你所浏览的技能文档正文；
  • 该服务按次计积分（当前 4 积分/次），内容未变的文档会被缓存、不会重复调用；
  • 代码块、命令、路径、环境变量会先摘出再翻译，不会被改写；
  • 切换语言后，技能概述、分类标签与仓库简介也会按目标语言翻译并缓存；
  • 可随时在右上角 ⓘ 中查看本提示、撤回同意或重新开启。

撤回翻译同意？

撤回后将不再发起新的翻译请求；本地已缓存的译文仍可查看，随时可在右上角 ⓘ 重新开启。

移入「自由技能」？

将把选中的 0 个技能的仓库归属清除为自由技能；归属错误也随时可在「整理归属」中重新归组。

暂不处理这些推断？

将把选中的 0 个待确认推断的技能移入「自由技能」，后续不再对它们自动推断归类；之后仍可随时手动归组。

⚙设置

API key 保存后以 OS 凭据库 + AES-256-GCM 加密落盘，绝不以明文出现；密钥永不回传浏览器明文。
