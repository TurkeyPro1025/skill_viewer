WHY

装得越多，越读不过来

skills CLI 把一个仓库的几十个子技能平铺装进本地目录，又被多个工具根共享。时间一长——

📖

读不懂

SKILL.md 几乎全是英文，几十篇逐个啃，读到一半就放弃。

→ 译站左原文右中文，逐段对照，边读边学。

❓

来源不明

技能文件夹混装，说不清哪个属于哪个仓库、是谁装进来的。

→ 译站lock 归属引擎精确归属，推断必标注。

🧩

重复混乱

同一技能在 .claude、.zcode、.agents 多处出现，像装了好几份。

→ 译站真实路径合并、拷贝计数、分岔多版本。

FEATURES

一个只读的本地知识库

读得懂、找得到、归属清楚。

块级中英对照

左原文右译文逐段对齐；代码块、命令、URL、路径先摘出、译后回填，永不被改写；中文文档单栏直出。

分类速查

不知道该调用哪个 Skill？中文概述一句话讲清「它是什么、什么时候用」；点分类胶囊或卡片标签，工程流程、写作、调试……即刻筛出候选，与搜索、仓库分组同页联动。内置种子覆盖常用技能，配置 LLM 自动补全其余。

lock 归属引擎

优先读 skills CLI 安装清单 .skill-lock.json；无记录时回退 .git 远端、frontmatter、LLM 推断，推断必标注「待确认」；手动归组最高优先。

多根去重

junction / symlink 按真实路径合并；内容一致的独立拷贝合并并计数；同名分岔展示为多个版本。

翻译学习友好

打开才翻、未变不重翻、并发只翻一份；超长文档自动分块、全局节流；附属文档按需翻译。

桌面 + 网页双形态

Windows 桌面版免 Node、托盘常驻；网页版 node server.js 即起；同一套界面与 API 契约。

SECURITY

安全与隐私优先

🔐

密钥加密

只在设置页录入，经 OS 凭据库（DPAPI / Keychain / secret-tool）+ AES-256-GCM 加密落盘；界面与接口只回掩码；可随时清除。

🏠

只在本机

默认只监听 127.0.0.1；所有写入请求强制同源校验，跨站伪造一律 403。

✉️

外发需同意

翻译开启前必须明确同意；LLM 可选，启用才发送；不配置时除翻译外零外发。

🛡️

只读不改

不安装、不卸载、不改写任何技能文件；扫描、去重、搜索全部本地完成。

FAQ

常见问题

不配置翻译和 LLM，能用吗？

能。浏览、归属、去重、搜索全部可用；中英对照需配置翻译服务；概述与分类对常用技能有内置种子，配置 LLM 后自动补全其余。

API key 存在哪里？安全吗？

经 OS 凭据库 + AES-256-GCM 加密后落盘，任何文件没有明文；界面只显示掩码（前3***后4）；凭据复制到其他机器无法解密，可随时清除。

会改动我的技能文件吗？

不会。只读扫描技能目录；手动归组等操作只写在自己的数据目录里。

分类标签从哪里来？

内置种子覆盖 vercel-labs/skills 等常用技能；配置 LLM 后自动为无种子的技能生成中文概述与 1-3 个分类标签；点技能卡上的标签即可筛选。

桌面版支持 macOS / Linux 吗？

桌面安装包目前仅 Windows；网页版（Node ≥ 20）跨平台，密钥在 macOS / Linux 走 Keychain / secret-tool。

翻译怎么计费？

走 UApiPro AI 翻译接口，每次调用 4 积分；超长文档自动分块，按调用次数计；内容未变不重复调用，同一文档并发只翻一份。
