WHY

The more you install, the harder it gets to read

The skills CLI flattens dozens of sub-skills from a repository into a local directory, and the same skills are shared across multiple tool roots. Over time:

📖

Hard to read

SKILL.md files are almost entirely in English. Reading dozens of them one by one is exhausting.

→ Skills Lingo original on the left, translation on the right, section by section — learn while you read.

❓

Unclear provenance

Skill folders are mixed together. It's hard to tell which repository a skill came from, or who installed it.

→ Skills Lingo a lock-file attribution engine assigns ownership precisely, and marks every inference.

🧩

Duplicates everywhere

The same skill shows up under .agents, .zcode and .claude, as if it were installed several times.

→ Skills Lingo real-path merging, copy counts, and separate versions for diverged copies.

FEATURES

A read-only local knowledge base

Understand it, find it, know where it came from.

Block-level bilingual reading

Original and translation aligned section by section. Code blocks, commands, URLs and paths are extracted before translation and restored afterwards — never rewritten. Chinese source documents are shown in a single column.

Categorized quick reference

Not sure which skill to call? A one-line summary explains what it is and when to use it. Click a category pill or a card tag — engineering workflow, writing, debugging and more — to filter instantly, alongside search and repository grouping. Built-in seeds cover common skills; an LLM fills in the rest.

Lock-file attribution engine

Reads the skills CLI install manifest .skill-lock.json first. Without a record, it falls back to the .git remote, frontmatter and LLM inference, marking inferred sources as "unconfirmed". Manual grouping always wins.

Multi-root deduplication

Junctions and symlinks are merged by real path; identical independent copies are merged and counted; diverged copies with the same name are shown as separate versions.

Translation-friendly by design

Translations are generated on first open, reused while the content is unchanged, and only one translation runs per document at a time. Long documents are chunked with global throttling; attached documents are translated on demand.

Desktop and web

A Windows desktop app that runs without Node and lives in the tray, plus a web version started with node server.js — same UI and API contract.

SECURITY

Security and privacy first

🔐

Encrypted keys

Entered only on the settings page, encrypted to disk with the OS credential store (DPAPI / Keychain / secret-tool) plus AES-256-GCM. The UI and API only return masked values; you can clear the key at any time.

🏠

Local only

Listens on 127.0.0.1 by default. Every write request enforces same-origin checks; cross-site forgery is rejected with 403.

✉️

Consent before any outbound call

Translation requires explicit consent before it is enabled. The LLM is optional and only sends data when enabled. Without configuration, nothing leaves your machine except translation requests.

🛡️

Read-only

Nothing is installed, uninstalled or modified. Scanning, deduplication and search all run locally.

FAQ

Frequently asked questions

Can I use it without translation or an LLM?

Yes. Browsing, attribution, deduplication and search all work. Bilingual reading requires a translation service. Summaries and categories have built-in seeds for common skills; an LLM fills in the rest.

Where is the API key stored? Is it safe?

The key is encrypted to disk with the OS credential store and AES-256-GCM, so no file contains plaintext. The UI only shows a mask (first 3 / last 4 characters). The encrypted credentials cannot be decrypted on another machine and can be cleared at any time.

Do the desktop and web versions share data?

Yes. Both use the same data cache, so switching between them requires no configuration, re-analysis, regrouping or re-translation.

Will it modify my skill files?

No. It scans skill directories read-only. Manual grouping and similar actions write only to its own data directory.

Does the desktop app support macOS or Linux?

The desktop installer is Windows-only for now. The web version (Node ≥ 20) is cross-platform, and keys use Keychain or secret-tool on macOS and Linux.

How is translation billed?

Through the UApiPro AI translation API (not an ad — just a good service; new accounts get 3,500 credits per month). Each call costs 4 credits. Long documents are chunked and billed per call; unchanged content is never re-translated, and concurrent requests for the same document are deduplicated.

Is the app interface available in English?

The website is bilingual. The app UI is currently Chinese; an English UI is planned for v1.2.0.
